# Solvian - AI Chatbot

An intelligent Python-based AI chatbot powered by advanced language models. Solvian provides conversational AI capabilities with natural language understanding and generation for various tasks and queries.

## Features

- 🤖 Intelligent conversational AI
- 💬 Natural language understanding and generation
- 🚀 Fast and responsive chatbot
- 🔧 Easy to configure and extend
- 📚 Support for multiple conversation contexts

## Requirements

- Python 3.8 or higher
- pip (Python package manager)

## Installation

1. Clone this repository:
```bash
git clone https://github.com/mrisllc/Solvian.git
cd Solvian
```

2. Create a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install required packages:
```bash
pip install -r requirements.txt
```

## Usage

Run the chatbot:
```bash
python main.py
```
